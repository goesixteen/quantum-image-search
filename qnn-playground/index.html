How it works

Each square's 8 pixel features become fixed RY/RZ angles on 4 qubits (the demos’ register; use + / − above layer 1 for up to 6), followed by learned rotations and a CNOT ring, in every layer. The measured averages give a score. Squares above the threshold become the oracle of Grover's search. The artwork, features, circuit and (with Load demo weights) the trained weights are the bus and crowd demos' own; scores match them to ~10−15.

Reading the picture

  • Boxes: one qubit's value for every square (blue +1 / orange −1).
  • Scene: blue = score, dashed = marked, frame = the square you're inspecting.
  • Spheres, arcs (details view): the qubits for that square; solid arc = entangled pair.
  • Faded gates can't affect the result.

Honest scorecard

  • All squares are scored first, so the default search shows how Grover behaves, not a speed-up. The coherent oracle (details view) runs the classifier inside the search.
  • A classical baseline matches the circuit on these tasks; Compare shows it.
  • Accuracy is on new patches from the same artwork. Everything is simulated.
