# Wanda website clip-art cast

Ten original transparent PNGs generated with the built-in image_gen tool. Each appears once in a compact group of two to four on the top-right edges of the game objects. CSS scales and mirrors the intact PNG files.

The complete prompt set, source paths, SHA-256 hashes and alpha checks are in [provenance.json](provenance.json). These decorative images are separate from the image searched by the frozen QNN.
