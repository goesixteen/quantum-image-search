# Pastel pedestrian artwork

The user requested a walking pedestrian-sign person in pastel red, then a
slightly darker red plus yellow and blue versions. The three final transparent
PNGs were produced with the built-in ImageGen tool by editing the same original
generated silhouette. These are original generated artwork, not copied sign
graphics or an externally licensed icon set.

The reference was first generated as a simple walking pictogram with a round
detached head, separated limbs, pastel red fill and transparent background. A
cleanup edit requested removal of stray edge pixels. Color edits then requested
red `#C66B6B`, yellow `#EAC35F` and blue `#7C9FCD`, while preserving the pose and
transparency. Requested colors are prompt targets, not exact-pixel guarantees.
The full final prompts, hashes and dimensions are in
[provenance.json](../dist/assets/ui-pedestrians/provenance.json).

All three are 1145×1374 RGBA PNGs with alpha extrema 0 and 255. They were copied
intact into the user-facing downloads and deployed asset directory; no pixel
editing or raster recoloring was performed outside ImageGen. The earlier light
red image and first cleanup candidate are retained in the external historical
archive. The source tool outputs remain at their default generated-image paths.

The latest user reference is a dense, overlapping arrangement of people, used
only as a layout reference; the watermarked stock graphic was not copied into
the site. The interface reuses these three original PNGs in compact seeded
crowds at key headings and primary actions. On viewport entry each figure
travels a straight path at 28 CSS pixels per second with linear timing toward
text-safe edges and corners. Different path lengths give different arrival
times. There is no easing, bobbing or leg-frame animation. Left/right CSS
reflections change display orientation without changing asset bytes.

Exit, resizing and backgrounding cancel movement. Re-entry can replay the
dispersal; the operating-system and site reduced-motion settings park figures
immediately. Decorative groups are inert, aria-hidden, pointer-events:none
siblings of existing labels and remain outside all search canvases. They cannot
enter model features, scores, the compiled oracle or Grover amplitudes. The
standing Wanda target and five backgrounds are unchanged. The previously
rejected photographic cutout theme remains removed.
