# Website clip-art cast

The user requested ten different clip-art people, then refined the arrangement to fewer people, in clusters of two to four standing only on top of objects toward their right side. The current layout uses each of the ten assets once: four on the map frame, three on Wanda’s card and three on Find Wanda. The figures are static, inert and decorative; none enters the analyzed image.

The PNG files are original artwork generated with the built-in image_gen tool, with transparent backgrounds. Generated alpha and full PNG bytes are preserved. Display scaling and left/right mirroring are CSS only. No third-party artwork license is claimed. Complete prompts, source paths, dimensions, hashes and transparency checks are in [the provenance record](../dist/assets/ui-clipart/provenance.json).

The lower explainer uses the same CSS color variable as Find Wanda, #d24e45, with a white/red striped seam. Diagram panels retain light backgrounds and circuit panels retain their contrast. No decorative people appear under the hood.
