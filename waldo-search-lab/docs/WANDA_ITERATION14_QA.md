## Changes

Find becomes **Stop search** during scanning and amplification. Stop or Escape
invalidates the old run, retains the image/placement and restores readiness.
Delayed results/errors cannot overwrite a newer action. Explicit busy ARIA keeps
lesson readiness correct while Stop remains enabled.

Gestures own their pointer ID, tool, offset and stroke. Unrelated fingers are
ignored; tool changes, cleared strokes, loading and lost capture end gestures
safely. Start over owns its sequential loaders; newer selections/edits cancel its
continuation rather than allowing old defaults to overwrite them.

The existing Reduce animations checkbox is visible in the circuit toolbar and
applies to circuit stepping and game animation, including a mid-run change.
Exact saved rounds and sampling weights are unchanged. A signed-chart key
identifies accepted/unmarked addresses and positive/negative amplitudes; singular
address labels are corrected.

The local server accepts `--port 4178` and `--port 0`, prints the selected URL and
gives an actionable occupied-port error. Two test loaders now prefer a normal
local Canvas installation, pinned to tested version 0.1.100. Static startup still
needs no npm installation/API key. README and quick-start separate website use,
engineering checks and optional training.
