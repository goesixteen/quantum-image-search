Iteration 10, October 11, 2026. The playful game stays separate from the explanation. The new six-step guide uses the same image, selected window, frozen model, compiled predicate and saved Grover trace as the live game.

1. **Pixels:** inspect a crop and eight classical descriptors. Read this image scans all 4,096 known-size windows, builds the actual oracle, and waits at round zero without sampling.
2. **QNN:** inspect real encoding and learned rotations. Previous/next gates and layer milestones complement play, pause and scrubbing. Step-only motion honors an explicit checkbox or system reduced-motion preference. Bloch vectors are reduced states of the full entangled four-qubit state. CNOT changes state at its endpoint; its linking pulse is a visual cue.
3. **Predicate:** compare the selected fine-window score with the best window in its address. The board separately shows threshold passes, suppression and retained marks. The actual supplied mark set defines f(j). A passing window can be suppressed; a low-scoring selected window can share an accepted coarse cell. Four classifier qubits are distinct from the location register (12 qubits at 64×64).
4. **Phase:** accepted amplitudes change sign, while squared magnitudes stay unchanged. Before/phase/diffusion charts share one amplitude scale for a given round.
5. **Interfere:** complete one round, jump to the first peak, or go past it. The Diffusion view previews the next round from the selected saved state. Round jumps clear old measurements. Attractive smoothing remains display-only.
6. **Measure:** sample the actual saved distribution with the existing unbiased measurement path. Unmarked samples are retained. The detector's accepted address is distinguished from the independent target-center check. An empty oracle abstains and disables sampling.
