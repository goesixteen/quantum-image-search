## Frozen model evidence and boundaries

All three live QNNs use four qubits, four data-reuploading layers, and **40 nominal fitted parameter slots**: 32 circuit angles, seven classical readout weights, and one bias. Each layer has feature RY/RZ encoding, learned RY/RZ rotations and the actual CNOT ring **0→1→2→3→0**. Eight engineered pixel features enter a learned circuit/readout; a validation-selected threshold creates the marked set.

Iteration 03's read-only parameter audit establishes that the four final learned **RZ slots 25, 27, 29 and 31 are prediction-insensitive**. They change basis phases; the final CNOT ring only permutes basis amplitudes, and the seven Z-product readouts depend only on basis probabilities. The **36 remaining slots influence predictions in the audited circuit**, but this count is not a claim of independence, identifiability or a 36-dimensional function family. Existing checkpoints are unchanged. See [hybrid-parameter-audit.json](../../waldo-search-lab/model/hybrid-parameter-audit.json).

## Scientific boundaries

All browser candidates are classically scored before compiling a fixed learned oracle. The demos show conditioned simulated Grover search, not a coherent threshold oracle or faster end-to-end image search. The round count uses the already-known marked count. False positives amplify; Grover does not repair a missed classification, although a true unmarked region can retain residual Born probability when a nonempty oracle is sampled. Classifier accuracy, accepted-set probability, target probability mass and one sample are distinct. The crowd site does not identify real people or validate operational person search. The constructed lesson supplies its own known target and is not an image-detector benchmark.
